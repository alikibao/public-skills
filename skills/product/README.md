# Product

Skills for deciding what to build and making it something people love.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[hit-products](./hit-products/SKILL.md)**: Shape, test and grow products people keep coming back to, using Mark Pincus's playbook: separate the instinct from the idea, break ideas into Proven / Better / New, replace the MVP with cheap tests and kill rules, grade ideas honestly, and design for engagement and retention.
