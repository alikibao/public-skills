# Business naming

An AI skill for naming businesses, products, and brands. It guides research, independent naming teams, candidate scoring, and preliminary language and trademark checks, then presents finalists on a visual board.

Use [the skill folder](business-naming/) or download [business-naming.skill](business-naming.skill). Start with: "Help me name my business."

Inspired by [David Placek's appearance in this video](https://www.youtube.com/watch?v=fDIW4W24VNk&t=1978s).
